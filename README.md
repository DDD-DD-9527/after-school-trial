# 课后服务 · 试用版

独立的课后服务试用项目：**开通学校 → 准备课程与师生 → 报名 → 课表 → 学生点名与教师考勤**。

当前版本 **V0.9**，包含运营管理员、学校管理员、教师、家长四种角色，适配桌面与手机。

## 技术栈（试用版取舍）

| 层 | 选择 | 说明 |
|---|---|---|
| 后端 | Fastify 5 + Kysely + TypeScript | 比 NestJS 少一层 DI 样板；路由与业务逻辑可直接迁移 |
| 数据库 | SQLite（better-sqlite3） | 免装数据库，单文件；生产切 PostgreSQL，SQL 基本兼容 |
| 前端 | Vue 3 + Vite + Tailwind v4 | 一个 H5 应用，桌面/手机共用 |
| 路由 | Vue Router | 按角色分流 |

> 当前使用 SQLite 和应用层学校隔离；正式方案中的 NestJS、PostgreSQL RLS 和组件体系尚未迁移。

## 启动

Docker Compose 和 Zeabur 部署步骤见 [DEPLOY.md](DEPLOY.md)。

```bash
npm install          # 首次
npm run db:init      # 初始化数据库 + 演示数据（会清空现有数据）
npm run dev:api      # 后端 http://localhost:5281
npm run dev:web      # 前端 http://localhost:5280
```

两个都要起。前端通过 Vite 代理把 `/api` 转发到 5281。

`db:init` 仅用于首次创建演示库，会清空已有数据。已有库直接启动 API，系统会备份并执行幂等增量升级，保留原账号和业务记录。

验证命令：`npm run verify`，包含 API 与前端回归测试、API TypeScript 检查和前端生产构建。

## 已实现的核心规则

- 名额扣减在 SQL 层原子完成（`UPDATE ... WHERE enrolled < capacity`），并发不超卖
- 时间冲突按**真实日期 + 起止时间**比较，相邻时段不算冲突
- 报名重复提交返回 409，不产生第二条记录
- 退课释放名额，但报名记录保留（不物理删除）
- 教师只能看到自己的课次，家长只能看自己的孩子
- 师生、课程、计划、报名、课次、账单、考勤、通知与导出按学校隔离
- 停用学校或账号对已有登录态立即生效；服务中学校至少保留一位有效校管理员
- 教师签到签退与学生点名分开记录；未打卡不自动认定缺勤，更正保留原始打卡与审计
- 跨标签切换账号会刷新旧页面身份，迟到请求不会覆盖新学校的编辑内容

## 试用版没做

在线支付、退款、请假审批流、外部消息推送、短信邀请与密码找回、套餐计费、跨校身份合并、小程序打包。

当前已有应用层多学校隔离、教师考勤审计和运营操作日志；数据库级租户隔离与正式部署验收留待正式系统实施。
